# 🐍 PyGame Accademy 🎮

Benvenuti nella **PyGame Accademy**, un percorso didattico strutturato per imparare la programmazione **Python** attraverso lo sviluppo di videogame 2D. 

Questo repository è pensato per studenti, docenti e appassionati che vogliono passare dalla teoria alla pratica creando piccoli progetti giocabili.

---

## 🚀 Cosa imparerai
Il corso è diviso in moduli che coprono i pilastri del Game Development:
- **Le basi di Python:** Variabili, cicli, liste e funzioni applicate al gioco.
- **Il Game Loop:** Gestione del tempo e aggiornamento costante dello schermo.
- **Grafica e Sprite:** Caricare immagini, gestire le animazioni e il movimento.
- **Collisioni e Logica:** Far interagire gli oggetti tra loro (proiettili, nemici, ostacoli).
- **Eventi:** Gestire input da tastiera, mouse e joystick.

## 🛠️ Tecnologie utilizzate
- **Linguaggio:** Python 3.x
- **Libreria:** [PyGame](https://www.pygame.org/)

## 📂 Struttura del Repository
- `/Esercizi`: Piccoli script focalizzati su singole meccaniche (es. far muovere un cerchio).
- `/Asset`: Immagini, suoni e font liberi da copyright pronti all'uso.
- `/Progetti`: Giochi completi realizzati passo-passo (es. cloni di classici arcade).

---

## 👨‍🏫 Note per i Docenti

## 💻 Come iniziare
Per eseguire i progetti sul tuo PC:

1. Clona il repository:
   ```bash
   git clone [https://github.com/dreamworker2023/PyGame-Accademy.git](https://github.com/dreamworker2023/PyGame-Accademy.git)

```

2. Installa la libreria PyGame:
```bash
pip install pygame

```


3. Scegli un esercizio ed eseguilo:
```bash
python nome_esercizio.py

```
